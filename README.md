# Focus Switch

Focus Switch（原名 Focus Next）是 MarginNote 的脑图卡片焦点切换插件，作者为乔木Joe。

当前正式版本为 Focus Switch 1.0.7，替换此前的 Focus Next 1.0.7，保留插件身份和已有设置。

新增“查看原题”处于测试阶段，测试包仍使用 1.0.7，正式包尚未包含此功能。

插件打开后，在脑图学习界面两侧显示“上一张”和“下一张”按钮。用户双击进入任意脑图卡片焦点后，插件会持续读取并记住宿主当前焦点；点击按钮会进入相邻的同级脑图卡片焦点，并定位、高亮目标卡片，不需要再次手动点击卡片。到同级第一张或最后一张时会停留并提示。

“下一张”默认位于学习界面右侧垂直居中位置，使用蓝色样式；按钮支持自由拖动，位置会自动保存并在下次打开学习界面时恢复。

单击插件图标显示或关闭宽约 340 点的窄设置面板，双击切换插件开启／关闭。单击等待约 0.3 秒以识别双击，双击不先弹出菜单；菜单有关闭按钮，高度不足时可滚动。关闭焦点切换会移除全部浮动按钮，包括查看原题；各子开关与按钮位置保留，重新开启时恢复。

拖动菜单标题栏可移动窄面板，松手后自动保存位置，下次打开或重启插件时恢复。位置按可移动区域的比例保存，横竖屏和分屏变化时限制在可见区域内；关闭按钮、开关与滚动区域各自保持原有操作。

菜单设置均保存在 `NSUserDefaults` 中：

- **启用焦点切换**：插件总开关，沿用旧开关状态，首次使用默认开启；关闭时隐藏全部浮动按钮。
- **跨层级切换**：默认关闭，仅切换同级兄弟；开启后按当前脑图前序深度优先顺序前进、严格逆序后退，包含父子卡片，树首尾停止。
- **显示卡片序号**：默认关闭。按钮以“上 3/20”“下 3/20”的紧凑样式显示当前同级序号与总数，数字较多时自动加宽，不记录作答情况；关闭序号或根卡片没有同级序号时显示“上一张”“下一张”。
- **显示上一张**：默认开启。关闭后只保留下一张，恢复开启时沿用原来保存的位置。
- **查看原题**：默认关闭，总开关开启时显示“查看原题”浮动按钮，可拖动并记住位置。选中 Daguanyuan、Yankean 或 Jifengjincao 导入题卡，或进入题卡焦点后点击，打开对应插件面板并定位原题；选中卡片优先于当前焦点。

查看原题复用导入题卡评论里的插件链接，需安装并启用对应 Bridge 插件及其依赖。普通卡片、缺失或无效链接、多个不同原题链接、题卡身份与链接冲突时提示后停止；多选时需先只选一张。旧题卡缺少插件链接时，可在来源插件中修复已导入题卡。不会改写题卡评论。

原题按钮与前后切换共用焦点读取和笔记 ID 识别逻辑，直接接收导航已识别的笔记，不再用更窄的属性检查过滤原生对象。可见焦点优先，重复读取不会退回滞后的焦点。宿主暂时清空焦点时沿用已记住的卡片；学习集 ID 可用时核对归属，宿主不提供 ID 时依靠学习集生命周期清除记忆。前后切换后同步更新该记忆，切换或关闭学习集、关闭总开关及断开场景时清除。此兼容逻辑仍需 iPad 真机验证；测试阶段无法识别焦点时附带“焦点检查3”诊断信息，确认原因后移除。

保留插件 ID `cn.marginnote.focus-next`、原持久化键及 `__FOCUS_NEXT_*__` 命名空间，以直接升级原插件并继承设置；Daguanyuan Bridge 的设置保持独立。

工具栏图标使用用户提供的“定位_聚点_焦点” PNG 资源。

上一张／下一张按顺序调用焦点切换和卡片定位接口，采用 MarginNote 定位后的显示效果，不锁定上一张的位置和比例。此操作无需 MN Utils，不读取或复制界面状态，不使用剪贴板。

用户在 iPad 上反馈，切换前比例大于 100% 时可能回到 100% 并出现短暂缩放；本版本保留已确认的显示效果。

进入并记住卡片焦点后，无需保持选中状态即可连续使用上一张／下一张；宿主暂时没有返回当前焦点时，沿用记住的卡片。打开其他学习集时清除记忆。

## 开发

```powershell
npm test
npm run build
```

`npm run build` 只生成开发测试包 `Focus Switch Test.mnaddon`。真机验证前，不能把内部脑图对象或定位接口视为长期稳定 API。

`npm run build:release` 生成 `Focus Switch-v<版本号>.mnaddon`，同名正式包存在时拒绝覆盖；测试确认并明确正式版本号后才构建正式包。
