# Focus Next

Focus Next 是 MarginNote 的脑图卡片焦点切换插件，作者为乔木Joe。

插件打开后，在脑图学习界面右侧显示“下一张”按钮。用户双击进入任意脑图卡片焦点后，插件会持续读取并记住宿主当前焦点；点击按钮会直接进入当前卡片的下一个同级脑图卡片焦点，不需要再次手动点击卡片。到同级最后一张时会停留并提示。

“下一张”默认位于学习界面右侧垂直居中位置，使用蓝色样式；按钮支持自由拖动，位置会自动保存并在下次打开学习界面时恢复。

插件工具栏命令 `toggleFocusNext:` 用于显示或隐藏右侧按钮；开关状态保存在 `NSUserDefaults` 中。关闭插件时按钮会从学习界面移除。

工具栏图标使用用户提供的“定位_聚点_焦点” PNG 资源。

## 开发

```powershell
npm test
npm run build
```

`npm run build` 只生成开发测试包 `Focus Next Test.mnaddon`。真机验证前，不能把内部脑图对象或定位接口视为长期稳定 API。
